# 📚 Readify React

A modern book library and reading tracker built with React.

Readify React is a web application designed to help users organize their books and manage their reading journey through a simple and user-friendly interface.

## ✨ Features

- Modern and responsive user interface
- Personal book library
- Reading progress tracking
- Easy book management

## 🛠️ Technologies

- React
- JavaScript
- CSS
- Vite
- HTML5

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/Neslikorkmaz/-ReadifyReact-.git
```

### 2. Navigate to the project folder

```bash
cd -ReadifyReact-
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.
